# NASA History Office Apollo panel diagrams

Retrieved 2026-09-23 from NASA's "Apollo Diagrams" page,
<https://www.nasa.gov/history/diagrams/apollo.html>. Each file is an exact copy
of the page's full-size GIF, renamed. These are U.S. Government works (NASA) and
in the public domain.

The source is the *Apollo Operations Handbook, Block II Spacecraft*
(15 October 1969), Command Module main display console. The six sheets are
Figure 3-1, sheets 1–6 of 7. Sheet 7 is not on NASA's page. Each sheet carries
the handbook's column/row grid around the panel border. That grid gives
positions on the console (for example, sheet 2 spans columns 28–54 and rows
A–AG). It is not a set of physical dimensions.

## Use

These files are a reference for laying out and labelling the Block II main
display console: control identity, grouping and relative position. They carry
no physical dimensions, so a panel built from them is a layout reconstruction,
not a measured one. The `.gdignore` keeps Godot from scanning the folder.
